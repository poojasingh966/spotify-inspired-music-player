# Spotify-Inspired Music Player 🎵

A Spotify-inspired music player user interface built using HTML and CSS.

## About the Project

This project is a frontend practice project created while learning HTML and CSS.

I customized the layout, music cards, images, colors, hover effects and play buttons to create my own version of a music player interface.

## Features

- 🎵 Spotify-inspired music player UI
- 📱 Navigation sidebar
- 🔍 Search section
- 🎶 Music category cards
- ▶️ Play buttons
- ✨ Hover effects
- 🖼️ Custom images and content
- 🎨 Dark music-player theme

## Technologies Used

- HTML5
- CSS3

## Project Status

This project currently focuses on the frontend UI.

JavaScript functionality will be added later.
